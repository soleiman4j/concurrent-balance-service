# سرویس مدیریت موجودی حساب‌های بانکی هم‌زمان (Java 21)

یک پیاده‌سازی حداقلی برای چالش برنامه‌نویسی [**Concurrent Balance Service**](<docs/Coding%20Challenge%20V2.pdf>).

این پروژه عملیات `credit` (واریز)، `debit` (برداشت)، `transfer` (انتقال وجه) و `getBalance` (دریافت موجودی) را پیاده‌سازی می‌کند. طراحی عمداً ساده و مبتنی بر حافظه (In-Memory)، تک‌پردازشی و تک‌ماشینی است.

## فناوری‌های مورد استفاده (Stack)

- **Java 21**
- **Spring Boot 3.5.16**
- **Maven**
- **JUnit 5**
- بدون نیاز به دیتابیس، HTTP API، Redis، Kafka یا Docker؛ هیچ‌کدام از این موارد در صورت‌مسئله الزامی نیستند.

## اجزای اصلی پروژه (Components)

- `BalanceService`: اینترفیس اصلی درخواست‌شده در چالش.
- `InMemoryBalanceService`: پیاده‌سازی منطق کسب‌وکار، مدیریت تراکنش‌ها و ایمنی در اجرای هم‌زمان عملیات.
- `BalanceException`: تعریف خطاها و دلایل مشخص شکست عملیات.
- `BalanceApplication`: نقطه شروع اجرای Spring Boot و شامل یک نمونه اجرای ساده و قابل پیش‌بینی.
- `Tests`: تست‌های مربوط به منطق کسب‌وکار، اعتبارسنجی ورودی‌ها، تراکنش‌های تکراری، هم‌زمانی، سرریز اعداد و جلوگیری از Deadlock.

### متد اضافی `createAccount`

متد `createAccount` یک قابلیت اضافی برای آماده‌سازی اولیه سیستم است.

این متد حساب‌ها را به‌صورت صریح ایجاد می‌کند. اگر شناسه حساب در سیستم وجود نداشته باشد، عملیات مالی مربوط به آن حساب رد خواهد شد.
